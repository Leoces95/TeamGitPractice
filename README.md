Descripción breve de la práctica: 

El objetivo fundamental de este proyecto es apropiarse de los conceptos fundamentales de integración continua mediante el uso de Git y Github, se desarrolla un proyecto WEB API 
con el objetivo de que cada integrante desarrolle una funcionalidad, suba y baje versiones del código fuente, así mismo realice pull request y resuelva conflictos de código entre otros.
